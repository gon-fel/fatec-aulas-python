## Como Executar os Scripts

Certifique-se de ter o Python 3 instalado. Execute no terminal o script da aula desejada, por exemplo:

```bash
python aula01/aula1.py
python aula03/atividade01_aula3.py
python aula04/atividade01_aula4.py
python aula06/atividade01_aula6.py
python aula07/atividade01_aula7.py
python aula12/atividade01_aula12.py
```
